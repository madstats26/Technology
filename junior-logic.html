Logic gates

A logic gate makes a decision using inputs that are either 0 (off, low) or 1 (on, high). Computers and control systems are made of logic gates.

Truth tables

A truth table lists every possible combination of inputs and the output for each. With 2 inputs there are 4 rows, and with 3 inputs there are 8 rows (2 × 2 × 2).

Logic in real life

  • A door alarm sounds if the system is armed AND the door is open.
  • A street light comes on if it is dark OR the manual switch is on.
  • A heater turns on if it is NOT warm enough.

Logic and control

Inputs come from sensors and switches. The logic gate is the process. The output controls an LED, buzzer or motor. You can test logic circuits in Tinkercad Circuits, and show the same decision as a flowchart.

Worked examples

1. An alarm sounds only when the system is armed (A) and the door is open (B). Which gate is needed?

AND. The alarm (output) is 1 only if A = 1 and B = 1.

2. A light switches on if it is dark (A) or the switch is on (B). Which gate is needed?

OR. The light is on if either input is 1.

3. Complete the truth table for a circuit with an AND gate whose output goes into a NOT gate.

4. A garden light must be on when it is dark (D = 1) and someone is detected (M = 1). Write the decision as a flowchart.

Start; read the light sensor; is it dark? If no, light off. If yes, read the movement sensor; is movement detected? If yes, light on; if no, light off; then repeat.
