Tinkercad guide

Build and simulate circuits, write simple Arduino programs and design 3D models.

Open Tinkercad ↗ Opens in a new tab

What is Tinkercad?

Tinkercad is a free tool that runs in your browser. It has two parts you use in class:

  • Circuits: build and test an electronic circuit on screen, with no risk to real components.
  • 3D Design: combine simple shapes to make a 3D model that can be 3D printed.

Your teacher will tell you how to sign in. Your designs save to your account.

Why simulate first?

  • You can find mistakes before you build the real circuit.
  • You can try ideas quickly, such as changing a resistor value.
  • It stops you damaging components, for example an LED with no resistor.
This page is a guide. Your teacher's brief, instructions and deadlines always come first, and menus can look slightly different from the screenshots and steps your class uses.

Build a circuit

Your first circuit: an LED with a resistor

  1. Create a new Circuit.
  2. Drag a battery (or an Arduino 5 V pin), a resistor and an LED from the components list onto the workplane.
  3. Click a resistor and set its value. For a red LED on 5 V with 20 mA, use R = (5 − 2) ÷ 0.02 = 150 Ω. A 220 Ω resistor also works and is slightly dimmer.
  4. Join the parts with wires so the current has one loop: battery → resistor → LED → battery.
  5. Check the LED direction: current goes in the longer leg (anode) and out of the shorter leg (cathode).
  6. Click Start Simulation. The LED should light.

Circuits to try

  • LED with a switch.
  • Two LEDs, first in series, then in parallel. What differs?
  • A night light using an LDR and a transistor.
  • A buzzer that sounds when a button is pressed.
  • A motor switched by a transistor with a protection diode.

Fault-finding checklist

  • Is every wire connected at both ends?
  • Is the LED the right way round?
  • Is there a resistor in series with the LED?
  • Do you have a complete loop from the supply and back?
  • Is the power on and the simulation started?
  • Use the multimeter to check where the voltage is missing.

Arduino code basics

An Arduino program has two main parts. setup() runs once at the start. loop() repeats forever. In Tinkercad you can use Blocks or Text code.

Blink an LED

void setup() {
  pinMode(13, OUTPUT);       // pin 13 is an output
}
void loop() {
  digitalWrite(13, HIGH);    // LED on
  delay(1000);               // wait 1 second
  digitalWrite(13, LOW);     // LED off
  delay(1000);
}

Button controls an LED

Connect the button between pin 2 and GND. INPUT_PULLUP turns on a built-in resistor, so the pin reads HIGH normally and LOW when the button is pressed.

const int buttonPin = 2;
const int ledPin = 13;
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}
void loop() {
  if (digitalRead(buttonPin) == LOW) {   // button pressed
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Light sensor (LDR) night light

void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  int light = analogRead(A0);        // 0 to 1023
  if (light < 300) {                 // dark
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}

The threshold (300 here) depends on your circuit. Use the Serial Monitor with Serial.println(light) to see real values.

Key ideas

  • Input: digitalRead (on/off) and analogRead (a value from 0 to 1023).
  • Output: digitalWrite. Decision: if / else. Wait: delay(milliseconds).
  • Draw a flowchart of your program before coding it.

3D Design

You build 3D models by combining simple shapes.

  • Shapes: drag a box, cylinder or other shape onto the workplane.
  • Size: click a shape and type dimensions, or use the ruler.
  • Hole: change a shape to a hole, then group it with a solid to cut it away. This makes slots, holes and cut-outs.
  • Group joins shapes together. Align lines shapes up exactly.
  • Check the model before printing: the right size, nothing floating, and flat surfaces on the bottom.

Before 3D printing

  • Export the model (for example as an STL file) and open it in the slicer (Cura) to set the layer height, infill and supports.
  • Thin walls and overhangs may need changing, or supports.
  • Think about print time and material.
